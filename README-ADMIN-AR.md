# لوحة إدارة مستر مينا دياب

## الملفات
- `admin.html`: واجهة لوحة الإدارة.
- `admin.js`: تسجيل دخول المدير وإدارة الكورسات والطلاب وإعدادات الرئيسية.
- `supabase-config.example.js`: نموذج إعدادات Supabase.
- `setup.sql`: جدول إعدادات الصفحة الرئيسية وسياسات RLS.

## 1) ربط Supabase
1. من Supabase افتح Project Settings > API.
2. انسخ Project URL و anon/public key فقط.
3. انسخ `supabase-config.example.js` إلى ملف جديد اسمه `supabase-config.js`.
4. ضع القيم في الملف الجديد.
5. لا تضع `service_role` أو أي secret key في ملفات الواجهة.

## 2) تجهيز قاعدة البيانات
شغّل `setup.sql` في SQL Editor. راجع سياسات RLS الموجودة ولا تعطلها.

## 3) حساب المدير
1. أنشئ حسابًا إداريًا من Supabase Authentication. صفحة الإدارة الحالية تستخدم بريدًا إلكترونيًا وكلمة مرور.
2. تأكد أن الحساب له صف في `public.profiles` بنفس UUID.
3. بعد التحقق من UUID، نفّذ أمر UPDATE المعلّق في نهاية `setup.sql` بعد استبدال AUTH_USER_UUID_HERE.
4. لا تجعل أي مستخدم admin عبر كود المتصفح أو نموذج عام.

## 4) النشر
ارفع `admin.html`, `admin.js`, `supabase-config.js` إلى جذر مستودع GitHub Pages. لا ترفع ملفًا يحتوي على مفاتيح سرية.
افتح `/admin.html` بعد اكتمال النشر.

## حدود النسخة الحالية
- إدارة الكورسات والاطلاع على بيانات الطلاب.
- حفظ عنوان ووصف الرئيسية في جدول `site_settings`.
- حفظ إعدادات الرئيسية لا يغيّر `index.html` تلقائيًا حتى نضيف له قارئ إعدادات.
- لا تتضمن هذه النسخة بعد إدارة الدروس، الحذف/التعديل الفردي للطلاب، رفع ملفات، أو محررًا كاملًا لكل صفحات الموقع.
- تأكد من أن سياسات RLS على `profiles`, `courses`, `lessons`, `enrollments` تمنح الوصول للمدير فقط حيث يلزم.
