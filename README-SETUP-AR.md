# منصة مستر مينا دياب — النسخة الكاملة مع لوحة الإدارة

## محتويات النسخة
- كل صفحات الموقع: الرئيسية، عن المستر، المراحل، المكتبة، التدريبات، التواصل.
- قسم كورسات جديد في الصفحة الرئيسية، يعرض الكورسات المنشورة من Supabase بعد ضبط الإعدادات.
- `admin.html`: دخول الإدارة وإضافة/تعديل/حذف الكورسات، وعرض بيانات الطلاب، وحفظ إعدادات نص الرئيسية.
- `setup.sql`: تجهيز جدول إعدادات الرئيسية.
- `supabase-config.js`: ملف إعداد المشروع (يجب تعديل قيمه).

## خطوات التشغيل
1. في Supabase > Project Settings > API انسخ Project URL و anon/public key.
2. افتح `supabase-config.js` واستبدل القيم التجريبية بقيم مشروعك العامة فقط. لا تستخدم service_role/secret key.
3. من SQL Editor شغّل `setup.sql`.
4. أنشئ حساب المدير من Authentication، وتأكد من وجود صف له في `public.profiles` بنفس UUID.
5. بعد التأكد من حسابك فقط، استبدل UUID في أمر UPDATE المعلق بآخر setup.sql ونفّذه من SQL Editor لإعطاء role=admin.
6. ارفع محتويات المجلد كلها إلى جذر مستودع GitHub Pages، ثم افتح `admin.html`.

## ملاحظات مهمة
- قسم الكورسات سيعرض الكورسات المنشورة من جدول `courses`.
- لوحة الإدارة الحالية تدير الكورسات وتعرض الطلاب وتحفظ نصوص الرئيسية بجدول `site_settings`. عرض نصوص الرئيسية المحفوظة يحتاج ربطًا إضافيًا في الصفحة الرئيسية.
- دخول الإدارة بالبريد وكلمة المرور في هذه النسخة.
- Supabase Auth لا يوفّر تسجيلًا آمنًا مخصصًا برقم هاتف وكلمة مرور من دون SMS بهذه الصورة مباشرة. لا تخزّن كلمات المرور في جدول profiles ولا تنفّذ التحقق منها في JavaScript. الأفضل تنفيذ نظام هوية مدعوم رسميًا أو بناء backend آمن للتحقق من الهاتف.
- جدول `profiles` و`courses` يفترض أنهما أُنشئا سابقًا كما في SQL الذي شغّلته. راجع السياسات قبل النشر.
- صورة المدرس: ضع الصورة في `images/mina-diab.jpg` لاستبدال العنصر البديل.
